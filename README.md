# FITLOG

A responsive workout management app built with **Next.js, TypeScript, Tailwind CSS, and Context API**. Users can browse workouts, create daily plans, save workouts for later, mark workouts as completed, and sort or manage their workouts easily.

## Technologies Used

* **Next.js** – Built with the Next.js App Router for modern web development.
* **React** – Used to build reusable and interactive UI components.
* **TypeScript** – Provides type safety and a better development experience.
* **Tailwind CSS** – Used to create a responsive and modern user interface.
* **DaisyUI** – Used for simple and reusable UI components.
* **React Icons** – Used for icons throughout the application.
* **React Toastify** – Used to show success and error notifications.
* **Context API** – Used to manage workout plans, saved workouts, completed status, and sorting.

## Key Features
1. **Workout Library** – Users can browse different workouts and view details like duration, difficulty, sets, reps, equipment, calories, and rating. 
2. **Today's Workout Plan** – Users can add workouts to their Today's Plan and manage them easily in one place. 
3. **Save for Later** – Users can save their favorite workouts and access them later whenever they need. 
4. **Mark as Completed** – Users can mark a workout as completed after finishing it and track their progress. 
5. **Sort & Delete** – Users can sort workouts by duration, calories, or rating and delete workouts from their plan or saved list.
